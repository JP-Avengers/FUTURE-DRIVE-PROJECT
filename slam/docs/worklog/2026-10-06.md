## 문제와 해결
- run12: 반시계 회차와 세션 간 링크 0개. 맵 간 자동 정합도 모두 실패했다(2D 상관은 180° 뒤집힌 후보와 동률, FPFH는 8시드 중 6개 뒤집힘, 이미지 매칭은 PnP 통과 0).
- `Vis/MaxDepth` 6·10m 제한(run14, run15)은 오도메트리가 89% 이상 끊겨 쓸 수 없었다. 카메라가 위로 5° 기울어 가까운 특징점이 부족했다.
- 스케일 오차 원인은 D435i depth가 멀수록 길게 나오는 것으로 판단했다. 보정 bag으로 다시 매핑해 해결했다.
- 단순 depth×s·fy×s 근사는 피치 5° 때문에 30m에서 20cm 틀려, v0.1s는 키프레임을 자세별로 다시 투영해 만들었다.
- 새 노트북에서 WSL mirrored 네트워크면 C++ 노드와 Python 노드가 서로 못 찾았다. NAT 모드로 바꿔 해결했다.
- run19 체인이 Windows 메모리 부족으로 중간에 종료됐다. WSL 메모리 상한을 16GB로 낮췄다.
- 30fps 전체 프레임 TSDF(`fullframe_tsdf`)는 차로 빈칸이 6.8% → 7.5~14.2%로 오히려 늘어 채택하지 않았다.
