# 주차장 맵 v0.5g — 11/8 손 촬영 반영 최종판 (B → C)

작성 2026-11-11 · 바탕: v0.5e_island (v0.5f의 둘레 실험층 정리판)

11/8 손 촬영(D435i 6회차) 작업을 마무리한 판입니다. **v0.5, v0.5e_island 또는 v0.5f 폴더를 이 폴더로 통째로 바꿔 쓰면 됩니다**(파일 이름이 같음). 좌표계, 차량 키프레임과 궤적, 주행 통로 바닥은 v0.5와 같습니다.

## 한눈에

| 구분 | 파일 | 쓰는 법 |
|---|---|---|
| **정식** | `geometry_clean_5cm.ply`, `floor_height.npz`, `cloud_3cm.ply` 등 | v0.5e_island와 같습니다. v0.5에 **가운데 섬 바닥(74㎡)** 이 더해졌습니다(섬 테두리 기준 0.1~0.3m) |
| **실험** | `hand_perimeter_nr3_EXPERIMENTAL.ply` | 둘레 보도·화단·벽 앞·동쪽 잔디의 손 촬영 형상(꼭짓점 색 있음). **정식 형상과 합치지 않았습니다.** 지역별로 0.2m~3m 어긋나 있으니 확인·배경용으로만 쓰세요 |

**C가 이미 받은 v0.5e와의 차이**: 정식 부분은 같습니다. 둘레 실험판만 바뀌었습니다. v0.5e_full_EXPERIMENTAL은 보정 전 배치라 1~4m 어긋나 있었고, 이 판은 대응점 21개로 다시 맞춘 배치입니다.

## 이 판의 목적과 쓰는 법

**주행 평가가 아니라, 시뮬레이터 화면을 현실과 비슷하게 만드는 용도**입니다. 둘레는 주행 경로에서 5~15m 떨어진 배경이라, 1~3m 위치 오차보다 v0.5 형상과 만나는 이음새가 더 중요합니다.

- 높이 3m에서 둘레를 내려다보는 시점 8곳에서 이음새를 확인했습니다. v0.5 주차장 바닥에서 지도 밖 바닥 격자를 지나 손 촬영 연석·보도·화단·벽으로 이어지며, 3D 틈이나 공중에 뜬 판은 없었습니다.
- 그림은 `qa/v05e/seam_*.jpg`에 있습니다. 왼쪽부터 v0.5f 정식, 정리 전, 이 판입니다.
- **주차장 안은 v0.5가 기준입니다.** 둘레층에서 주차장 안(v0.5가 바닥을 본 영역)에 들어온 바닥·주차선 조각은 뺐습니다. 위치가 어긋난 주차선이 겹쳐 보이지 않게 하려는 것입니다.
- **둘레 연석을 v0.5 연석에 자동으로 붙이는 방법은 쓰지 않았습니다.**
  - 손 촬영은 주로 벽 쪽 화단 연석을 보고, v0.5는 주차장 쪽 연석을 봅니다. 그래서 둘을 붙이면 보도가 사라졌습니다.
  - 검증된 남쪽 구역에서도 2~4m를 옮기라는 틀린 값이 나왔습니다.

## 둘레 실험층의 정확도

지역별 정확도는 `qa/v05e/hand_perimeter_accuracy.png`에 색으로 표시했습니다.

| 지역(그림 색) | 어긋남 | 근거 |
|---|---|---|
| 남쪽·남서(초록) | **0.2~0.4m** | 소화전, 파란 보행자 통로 안내판, 남쪽 연석, 남서 둥근 연석. 대응점을 하나씩 빼고 다시 예측한 교차 검증 값 |
| IT1 입구(노랑) | 1~2m | 손 촬영 회차끼리도 2m 안팎으로 어긋남 |
| 북쪽·북서(주황) | 1~3m | 북서 보도 가로수 구덩이, 북쪽 보도 대응점 각 하나뿐. 벽 송수구로 확인하면 0.6~1.5m |
| 북동·동쪽(빨강) | 미검증 | v0.5에 비교할 형상이 없음 |

- 11/8 당시 서 있던 차와 사람이 일부 남아 있을 수 있습니다. 주행 통로(D 기준 경로 ±2.35m) 안의 조각은 뺐습니다.
- 높이는 키프레임마다 v0.5 바닥에 맞췄습니다. v0.5 바닥이 없는 둘레 바깥은 주변 값으로 보간한 높이입니다.
- 남쪽 둘레는 v0.5에 이미 형상이 있어, 새로 더해진 부분이 적습니다.

## 정식 부분 (v0.5e_island와 같음)

- `floor_height.npz`의 `conf` = 4는 손 촬영 바닥으로 채운 칸입니다(61㎡).
- `keyframes_hand_fecen/` 104장은 섬 바닥에 사진 텍스처를 입힐 때 씁니다.
- `example_tsdf.py`가 이 키프레임을 자동으로 인식합니다. 사진은 11/8 촬영이라 차량 촬영과 밝기가 다릅니다.
- `hand_added_v05e.ply`는 정식으로 더한 섬 부분만 따로 담은 파일입니다.

자세한 표와 파일 설명은 `CHANGES.md`와 v0.5e 문서에 있습니다(이 폴더의 `qa/v05e/` 포함).

## 더 정밀하게 하려면

둘레는 v0.5 차량 촬영이 10~17m 떨어져서만 본 곳이라, 기준 자체가 1~2m 불확실합니다. 현장에서 줄자로 거리 몇 개만 재면 둘레를 정식판에 넣을 수 있습니다. 예를 들면 주차장 연석에서 벽 송수구, 연석에서 맨홀, 동쪽 주차열 끝선에서 연석까지의 거리입니다.
