# 실내 복도 맵 v0.1 — RealSense (B → C)

작성 2026-11-13 · 입력: 11/8 실내 촬영 `inside_2` (복도 왕복 109 m, D435i 손 촬영)

C의 실내 틀(`recon/configs/templates/indoor_rtabmap.yaml`)에 바로 넣을 수 있는 형식입니다. 실제 복도 데이터로는 첫 판이라, 틀이 도는지 확인하는 용도로 먼저 보냅니다.

## 쓰는 법

`recon/configs/corridor.yaml`의 ★ 줄만 채우면 됩니다.

```yaml
input:
  root: ~/recon_data/corridor_v0.1      # 이 폴더 (영문 경로)
  keyframes: keyframes
  poses: trajectory_camera_optical.txt
# geometry:                             # B 형상 메쉬를 쓰려면 켬 (끄면 C의 tsdf.py가 키프레임으로 만듦)
#   mesh: geometry_tsdf_2cm.ply
```

## 들어 있는 것

| 파일 | 내용 |
|---|---|
| `keyframes/rgb · depth · calib/<id>` | 키프레임 281장. 640×480, depth는 mm·RGB 정렬·거리 보정(c=0.007) 완료. 내부 파라미터는 한 종류 |
| `trajectory_camera_optical.txt` | 시각 x y z qx qy qz qw id. 카메라 광학 좌표계 → 맵 |
| `trajectory_camera_link.txt` | 같은 궤적의 camera_link 자세 |
| `geometry_tsdf_2cm.ply` | 색 있는 2 cm TSDF 메쉬(depth 3 m 안). 선택 사항 |
| `topview.png` | 메쉬를 위에서 본 그림(3 cm/화소, 위쪽 숫자는 x m) |
| `measurements.md` | 맵에서 잰 복도 폭 · 벽이 끊긴 곳. 줄자 실측과 대조용 |
| `qa/` | 키프레임 사진과 같은 자세 렌더 대조, 가는 길 · 오는 길 벽 겹침 그림 |

## 좌표계

- **건물 좌표**: 복도 축이 x, 출발점이 원점, 바닥이 z = 0, 단위 m, Z 위. 로비는 +y 쪽입니다.
- 주차장 맵(v0.5 계열)과는 이어져 있지 않은 별도 좌표입니다.

## 만든 방법

RTAB-Map(IMU 중력 제약)으로 매핑한 뒤 세 가지를 보정했습니다.

1. **바닥 수평**: 키프레임마다 자기 depth의 바닥 높이를 재서 바닥을 z = 0으로 맞췄습니다. 보정 전에는 바닥이 0.73 m 출렁였습니다.
2. **회전**: 키프레임마다 벽 방향을 재서 회전 오차(−3.2 ~ +2.3°)를 바로잡고 궤적을 다시 적분했습니다.
3. **좌우**: 복도 벽을 직선 두 줄로 보고 키프레임을 벽 선에 맞췄습니다(보정량 −0.42 ~ +0.46 m).

보정 전에는 오는 길이 가는 길과 2 m 어긋나 복도가 두 겹이었습니다.

## 품질

| 항목 | 값 | 근거 |
|---|---|---|
| 가는 길 · 오는 길 벽 어긋남 | 중앙 3.0 cm (5 cm 안 57%, 15 cm 안 70%) | 오는 길 벽 점에서 가는 길 벽까지 거리 |
| 복도 폭 | 2.53 m (10~90%: 2.44~2.58) | 양쪽 벽을 함께 본 키프레임 92장. 다른 회차(inside_1_reverse)에서도 2.54 m |
| 복도 방향(x) 일치 | 0.2~0.3 m 안 | 확대 겹침 그림을 눈으로 본 값(수치 검증 아님) |
| 카메라 높이 | 중앙 1.20 m | 바닥 기준 |

줄자 실측과는 아직 대조하지 않았습니다.

## 한계

- **벽 위쪽과 천장이 없습니다.** 카메라가 아래로 약 24° 기울어 있어서 벽은 바닥에서 1.6 m 정도까지만 찍혔습니다. 로봇 카메라 시점에서는 위쪽이 구멍으로 보입니다.
- **직선 복도 가정**: 복도 벽이 직선이고 폭이 일정하다고 보고 맞췄습니다. 왕복 중 한쪽 길(오는 길)에서는 벽이 46 m 내내 7 cm 안에서 직선이었습니다. 평면도와는 대조하지 않았습니다.
- **로비**: 유리벽 구간은 형상이 지저분합니다. 로비 안에서의 좌우 위치는 앞뒤 복도 값으로 보간했습니다.
- **회차 1개만 사용**: 나머지 4개 회차는 아직 넣지 않았습니다.
  - `inside_1_reverse`: 매핑 성공. 맵에 넣지 않고 검증용으로 남길 예정입니다.
  - `inside_1`: 처음 설정에서 위치 추적이 끊겼고, 재시도에서 대부분 복구됐습니다.
  - `inside_leftwall`, `inside_rightwall`: 흰 벽을 향해 찍은 회차라 위치 추적이 불안정합니다. 벽 위쪽을 채울 수 있는 자료라 처리 방법을 찾고 있습니다.
