작성 2026-11-10

> **둘레가 1~3m 어긋나 있습니다. 주행 평가나 최종 씬에는 쓰지 마세요.** 어떻게 보이는지 확인하려고 만든 판입니다. 정식 판은 `map_v0.5e_island`입니다.

## 쓰는 법

`map_v0.5e_island` 폴더를 복사한 뒤, 이 폴더의 파일로 같은 이름을 덮어쓰면 됩니다. `geometry_clean_5cm.ply`, `floor_height.npz`, `floor_height.json`, `cloud_3cm.ply`, `ground_extended_0.5m.ply` 5개입니다. 좌표계는 v0.5와 같습니다.

| 파일 | 내용 |
|---|---|
| `geometry_clean_5cm.ply` | v0.5 + 손 촬영 6회차 전체에서 v0.5 형상이 없는 곳(삼각형 150만) |
| `hand_added_v05e_full.ply` | 새로 넣은 부분만(꼭짓점 색 있음) |
| `floor_height.npz` | 관측이 없던 칸 31,596칸(316㎡)을 손 촬영 바닥으로(`conf` = 4) |
| `cloud_3cm.ply`, `ground_extended_0.5m.ply` | island판과 같은 방식 |
| `floor_conf_v05e_full.png` | 채운 칸 지도 |

## 들어간 것

- 둘레 보도(붉은 벽돌), 보도 턱, 화단·울타리, IT1 입구 계단과 차양, 가운데 섬 바닥
- 주행 통로(D 기준 경로 ±2.35m) 안으로 들어온 조각(11/8 차·기둥·계단 끝 12개)은 뺐습니다.
- 통로 밖의 11/8 주차 차 일부와 사람은 남아 있을 수 있습니다.

## 얼마나 어긋났나 (v0.5 정사 영상·점군과 손 촬영의 대응점)

| 자리 | 어긋남 |
|---|---|
| 가운데 섬 | 0.1~0.3m |
| 남쪽 연석 | 0~0.3m(연석 수직) |
| IT1 입구 배수구 | 1.4m |
| 남서 둥근 화단 연석 | 약 2.6m |
| IT1 계단 윗변(일부 회차) | 2.5m |
| 북서 보도 가로수 구덩이 | 약 3.9m |
| 북쪽 보도 | 약 3.5m |

- 손 촬영은 루프가 거의 닫히지 않아 지도 자체가 휘어 있습니다. IT1 입구에서는 회차끼리도 2~2.5m 어긋납니다.
- 대응점 19개로 비강체 보정도 시험했습니다. 대응점 자리는 0.2~0.9m로 맞았지만, 하나씩 빼고 예측하면 1~3m가 틀렸습니다. 그래서 이 판에는 보정을 넣지 않았습니다.
- 둘레를 제대로 넣으려면 둘레를 담은 독립 기준이 필요합니다. 예를 들면 Polycam 스캔, 줄자 측정, 항공 사진입니다.
