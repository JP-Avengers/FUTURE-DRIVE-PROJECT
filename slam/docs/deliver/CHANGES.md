### v0.4b — 본네트 기준판

- **10/9·10/10 본네트 시계 4회차 맵을 기준으로 바닥 형상을 새로 만듦.** 본네트 반시계, 10/5 지붕 데이터는 기준에 맞춰 휘어 빈 곳만 채움. **v0.3 바닥과 높이가 구역별로 ±15~20cm, 수평이 보통 7~20cm 달라짐**(좌표계는 같음).
- 키프레임 바닥 − 메시 바닥: v0.3 +6.2cm → **+3.0cm**(C 지적 1). 이음새 단차 0.5m 칸별 중앙 6.5cm → 5.2cm.
- 바닥 빈칸: 차로 3.5% → 1.6%, 주변 15.9% → 11.2%(1㎡ 이상 7곳, 최대 22.2㎡).
- 키프레임 묶음 이름 변경: `keyframes_bonnet_cw/`(508장), `keyframes_bonnet_ccw/`(575장), `keyframes_roof_cw/`(v0.3 `keyframes/`, 437장), `keyframes_roof_ccw/`(v0.3 `keyframes_ccw/`, 253장). 지붕 키프레임도 자세가 바뀜.
- `example_tsdf.py`: `--bonnet`, `--roof`, `--all`, `--only <묶음>`.
