# 주차장 맵 v0.5 — 주행 통로 정리판 (B → C)

작성 2026-10-13 · 바탕: v0.4b(본네트 카메라 기준)

**v0.4b의 형상 메시와 점군을 정리하고, 바닥을 한 장으로 바꾼 판**입니다. 좌표계(원점·축·단위), 키프레임, 궤적은 v0.4b와 같습니다. 바닥 높이 지도와 지도 밖 바닥을 새로 넣었습니다.

## 왜 고쳤나

10/12 Isaac Sim 첫 주행 영상과 D가 기록한 걸림 자리를 B 메시와 키프레임 사진으로 대조했습니다.

- **걸림·언덕·검은 판 조각·공중 덩어리는 B 메시에서 왔습니다.** 원인은 세 가지였습니다.
  - 바닥 밑 최대 2m까지 있던 쓰레기 면
  - 지붕 카메라와 회차별 채우기에서 온 바닥이 본네트 바닥과 10~30cm 어긋난 채 여러 겹으로 남은 것
  - 바닥 위 20~50cm의 잡음 덩어리와 지나간 사람의 잔상
- 해당 지점의 키프레임 사진은 모두 평평한 아스팔트였습니다.
- 주행 통로(기준 경로 ±2.35m)는 100% 본네트 카메라 바닥이라, 추가 촬영 없이 정리로 해결했습니다.

## 만든 방법

1. **바닥 높이 지도**
   - 본네트 9회차의 원본 depth를 **5m 안만** 써서 회차별로 TSDF를 만들었습니다. 칸마다 회차별 바닥 높이를 구한 뒤 회차 사이 중앙값을 썼습니다(회차 사이 폭 중앙 5cm). 날마다 다른 주차 차나 지나간 사람에 흔들리지 않습니다.
   - 본네트가 못 본 칸에는 지붕 카메라 바닥을 넣었습니다. 지붕 바닥은 본네트보다 평균 6cm 낮게 어긋나 있어서, 그 차이를 매끈하게 빼서 맞췄습니다.
   - 빈 칸은 둘레에서 보간했습니다. 지도 밖은 주차장 전체 평면(기울기 0.56°)으로 부드럽게 이어지도록 외삽했습니다.
   - 차로(본네트 궤적 2.5m 안)는 σ 0.2m로 한 번 더 다듬었습니다.
2. **바닥 밑 면 삭제**: 지도보다 본네트 칸은 5cm, 지붕 칸은 15cm, 잰 적 없는 칸은 80cm 넘게 아래인 면을 지웠습니다.
3. **바닥 한 장**: 바닥 ±6cm 안의 수평 면(스캔 바닥 층)을 지우고 지도로 10cm 격자 바닥 한 장을 깔았습니다. 연석과 벽 같은 세로 면은 남겼습니다.
4. **차로 잡음 삭제**: 차로는 본네트 궤적 2m 안과 D 기준 경로 2.5m 안입니다.
   - 바닥 위 25cm 이하의 수평 면을 지웠습니다.
   - 본네트 키프레임 depth로 회차별 판정을 했습니다. 2개 이상 회차가 그 점 너머를 봤고, 그 점을 제대로 본 회차가 1개 이하이면 지웠습니다. 이렇게 사람 잔상, 혹, 뜬 덩어리를 지웠습니다.
   - 크고 높은 덩어리(넓이 3㎡·높이 60cm 넘음, 즉 주차 차)는 판정하지 않았습니다.
5. **조각 정리**
   - 어디서나: 1~3삼각형 점, 바닥 위 15cm 안의 납작한 조각(본네트 칸은 25cm)
   - 차로 안: 작은 조각, 뜬 덩어리, 바닥 위 30cm 이하의 1㎡ 미만 혹
   - **차로 밖의 나무, 주차 차, 뜬 조각은 남겼습니다.**
6. **점군**: 같은 기준으로 바닥 밑 점, 차로의 낮은 점, 정리된 메시에서 8cm 넘게 떨어진 차로 점, 외딴 점을 지웠습니다.

## C에게

- **파일 이름**: 형상 파일 이름이 `geometry_clean_5cm.ply`로 바뀌었습니다.
- **바닥 높이 지도**: `floor_height.npz`는 `Ground.load`로 바로 읽힙니다. 바닥이 이미 한 겹이라 `single_floor`의 잡음 규칙(`debris_*`, `flat_h_m`, `collision_low_h_m`)은 대부분 필요 없을 것으로 봅니다.
- **지도 밖 바닥**: 10/13 멘토 의견("맵이 더 현실 같으면")에 따라 B는 10/7 규칙("지도 밖 바닥과 배경 벽은 만들지 않는다")을 따르지 않기로 했습니다. `ground_extended_0.5m.ply`를 보이는 바닥으로 쓰거나 `floor_height.npz`로 직접 깔 수 있습니다(`conf` 0 = 외삽). 구역(아스팔트, 풀밭, 보도) 경계와 건물·차·나무 위치는 다음에 따로 드립니다.
- **색 입히기**: 우선순위는 v0.4b와 같습니다(본네트 시계 → 본네트 반시계 → 지붕). 새 바닥은 키프레임 바닥과 높이가 더 잘 맞습니다.
