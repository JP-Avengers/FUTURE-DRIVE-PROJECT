# 손 촬영(feature_*) 정합 분기점 — 2026-11-10

동기의 걸은 경로(확인 자료)를 받기 전에, 아래 가정을 바탕으로 정합을 진행한다.
확인 자료가 오면 이 분기점(git 태그 `b-fe-align-cp1`)으로 돌아와 가정을 하나씩 다시 확인한다.

## 가정

| 번호 | 회차 | 가정 | 근거 | 확인 방법(자료가 오면) |

## 이 분기점 이후 작업
- fecen: 섬 테두리 기준 ±1m·±4° 다듬기 → 섬 바닥 채우기 후보
- feit1 등 나머지 회차: 같은 방식(출발점·특징 구역 판단 → 고정 탐색 → 육안 확인)
- 각 회차 판단은 이 표에 가정으로 추가한다.

## 되돌리는 법
`git checkout b-fe-align-cp1 -- slam/` (스크립트·문서). 정합 결과 파일은 `~/b_slam/exports/align_<run>_pin/`에 회차별로 따로 저장되므로 기존 결과를 덮어쓰지 않는다.
