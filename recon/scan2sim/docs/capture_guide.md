# 촬영 안내 — 아이폰으로 실내를 찍어 올리기

scan2sim 에 올릴 실내 촬영본을 찍는 법입니다. 아래 숫자는 지금 엔진이 실제로 쓰는 기준값이고(`docs/CONTRACT.md` 6 · 7장, 11.24 main), 기준이 바뀌면 이 문서도 같이 고칩니다. **실제 기기로 아직 확인하지 못한 것은 맨 아래에 따로 모았습니다.**

## 준비

- LiDAR 가 있는 아이폰 · 아이패드(Pro 계열)와 **Stray Scanner** 앱.
- 완성된 메쉬를 올릴 때는 Polycam 같은 스캔 앱이 내보낸 **GLB** 파일.
- 찍기 전에 **사람이 없는 상태**로 만듭니다. 사람이 찍히면 그대로 맵의 장애물이 되고, 엔진은 지워 주지 않습니다.

## 찍는 법

| 이렇게 | 왜 (엔진이 하는 일) |
|---|---|
| 촬영을 시작하고 **1초쯤 가만히** 있다가 움직입니다 | 시작 직후에는 폰 위치 추정이 튀어서 처음 1초를 버립니다 |
| **천천히** 움직입니다. 보통 걸음의 절반쯤 | 초속 1.5 m 보다 빠른 장면은 흐려서 버립니다. 전체적으로 초속 0.8 m 를 넘으면 "촬영 속도가 빠름" 주의가 붙습니다 |
| 벽과 바닥에서 **0.5 ~ 3 m** 거리를 둡니다 | 3 m 보다 먼 곳은 맵에 들어가지 않습니다. 넓은 방은 가운데에 서서 돌지 말고 벽을 따라 걸으며 찍습니다 |
| **바닥이 넓게** 찍히게 폰을 조금 숙입니다 | 바닥이 2 m² 보다 적게 찍히면 "바닥을 찾지 못함"으로 실패합니다 |
| **5 m 넘게** 걷고, 가로로 3 m 넘는 범위를 찍습니다 | 그보다 좁으면 "촬영 범위가 좁음" 주의가 붙습니다. 로봇이 다닐 맵으로 부족합니다 |
| 한 번에 **5분 안쪽**으로, 방 하나나 복도 한 구간씩 찍습니다 | 길어질수록 올리는 시간과 처리 시간이 늘고, 폰 위치가 조금씩 틀어진 것이 쌓입니다. 되돌아온 자리를 맞춰 주는 보정은 없습니다 |
| 유리 · 거울 · 번쩍이는 바닥은 비스듬히, 가까이에서 찍습니다 | 깊이가 잘 안 잡혀 "쓸 수 있는 깊이가 적음" 주의가 붙습니다 |
| 2초보다는 길게 찍습니다 | 2초 또는 100장보다 짧으면 실패합니다 |

한 바퀴 돌아 처음 자리로 돌아오면 처음과 끝이 얼마나 어긋났는지 볼 수 있어 좋습니다. 다만 어긋난 만큼 바닥이 두 겹으로 찍힐 수 있고, 이것은 진단 단계가 결함으로 알려 줍니다.

## 올리는 법

1. Stray Scanner 의 **촬영 폴더 하나를 통째로** zip 으로 묶습니다. 폴더 안에 `rgb.mp4` · `odometry.csv` · `camera_matrix.csv` · `depth/` · `confidence/` 가 있어야 합니다.
2. 한 번에 **촬영 하나만** 올립니다. zip 안에 촬영 폴더가 여러 개면 받지 않습니다.
3. 화면의 "1. 파일 선택"에서 zip(또는 GLB)을 고르고 "진단 시작"을 누릅니다.
4. 올리는 동안에는 화면을 켜 두고 다른 앱으로 넘어가지 않습니다(넘어갔을 때 어떻게 되는지는 아직 확인 전입니다).

받는 크기: 파일 하나 4 GB 까지, zip 은 풀었을 때 6 GB · 파일 10만 개까지.

## 화면에 이런 말이 나오면

| 나오는 말 | 뜻 | 할 일 |
|---|---|---|
| 촬영 범위가 좁음 | 5 m 도 안 걸었거나 범위가 3 m 가 안 됨 | 더 넓게 걸으며 다시 찍기 |
| 촬영 속도가 빠름 | 전체적으로 초속 0.8 m 보다 빨리 움직임 | 더 천천히 다시 찍기. 결과는 나오지만 형상이 성깁니다 |
| 쓸 수 있는 깊이가 적음 | 깊이가 잡힌 화소가 절반이 안 됨 | 더 가까이에서, 유리 · 거울을 피해서 찍기 |
| 촬영이 길어 키프레임 간격을 넓힘 | 고른 장이 2,000장을 넘어 듬성듬성 골랐음 | 그대로 써도 됩니다. 세밀함이 필요하면 구간을 나눠 찍기 |
| 되돌아온 자리 보정 없음 | 아이폰 촬영본에는 **늘** 붙는 안내 | 할 일 없음 |
| 바닥의 n% 가 다른 높이에 찍힘 | 폰 위치가 틀어져 바닥이 두 높이로 찍힘 | 진단 단계의 결함 위치를 보고, 심하면 더 짧게 다시 찍기 |
| 촬영이 너무 짧음 | 2초 또는 100장 미만 | 더 길게 찍기 |
| 바닥을 찾지 못함 | 바닥이 2 m² 도 안 찍힘 | 폰을 숙여 바닥이 보이게 다시 찍기 |
| 촬영 폴더에 필요한 파일이 없음 | zip 에 폴더 일부만 들어감 | 촬영 폴더를 통째로 다시 묶기 |
| zip 안에 촬영 폴더가 여러 개임 | 촬영 여러 개를 한 zip 에 넣음 | 하나씩 따로 묶기 |
| zip 파일을 열 수 없음 | 파일이 깨졌거나 올리기가 덜 끝남 | 다시 묶어 다시 올리기 |
| zip 이 너무 큼 | 풀면 6 GB 또는 파일 10만 개를 넘음 | 더 짧게 찍기 |

## 아직 실제 기기로 확인하지 못한 것

확인하는 대로 위 본문으로 옮깁니다.

| 확인할 것 | 방법 | 결과 |
|---|---|---|
| 아이폰 '파일' 앱에서 촬영 폴더를 길게 눌러 압축한 zip 을 Safari 의 파일 선택에서 고를 수 있는지 | 실제 기기로 해 봄 | (11/25 예정) |
| Stray Scanner 에 프레임 수(초당 장 수) 설정이 있는지, 낮추면 용량과 복원 품질이 어떻게 되는지 | 앱 설정 확인 · 같은 방을 두 설정으로 찍어 비교 | (11/25 예정) |
| 폰에서 올리는 데 걸리는 시간 — 와이파이 · 이동통신 각각 | 터널 주소가 생긴 뒤(M1) 5분 촬영본으로 잼 | |
| 올리는 중에 화면을 끄거나 다른 앱으로 가면 어떻게 되는지 | 실제 기기로 해 봄 | |
| 5분 촬영본의 실제 크기 | 찍어서 잼(계획서의 약 880 MB 는 추정) | |
