# 11.11 중앙 장애물: Nav2 가 피하는 쪽이 영상에 보이는 기하로 정해지나 (교사 데이터만, 모델 없음)

## 한 줄

**중앙 장애물(|lateral| ≤ 0.15 m)에서는 기하가 쪽을 약하게만 정한다.**

- 장애물 오프셋의 반대쪽으로 지나간다는 규칙의 적중률은 77/113 = 68 % [59–77] 이다.
- 위치(구간 × 방향)를 더해도 한 녹화씩 빼고 맞힌(LORO) 적중률이 74 % 이다.
- 같은 배치를 두 번 녹화하면 같은 쪽으로 지나간 것이 33/44 = 75 % 뿐이다. 따라서 어떤 영상 규칙도 넘기 어려운 상한은 ≈ 85 % [72–93] 이다.

반대로 옆 장애물(|lateral| ≥ 0.3 m)은 136/143 = 95 % 가 반대쪽으로 지나간다. 0.4 m 이상은 서쪽 사선 구간을 빼면 77/77 이다.

→ (가) 다봉 평균은 **데이터 자체의 한계로 실재**한다. 중앙 장애물은 '같은 쪽' 규칙으로 다시 녹화해야 한다(장애물을 0.3–0.4 m 이상 비켜 두기).

  - 장애물 자리는 `obstacle_diag.scenario` 로 얻었다. 녹화된 `obstacle_dist`(중심 거리 − 반지름)와 비교하면 원뿔 · 원기둥 136 건이 ±0.01 m 안에서 맞는다(상자는 반지름 정의 차이로 +0.05–0.28 m).
  - parking_r3_obs_cones 의 쌍 콘(같은 s 에 0 · −0.7 m)은 제외했다(중앙 2 · 옆 2).
- **지나간 쪽(정답)** = 장애물과 나란해지는 순간, 기준선 좌표에서 (로봇 옆 위치 − 장애물 옆 위치)의 부호. 진행 방향 왼쪽이 + 이다.
  - 그 순간 장애물과의 옆 거리는 최소 0.77 m 이고 모호한 조우는 0 이다. 로봇 좌표계로 따져도 268/268 이 일치한다.
- **교사 ω 적분과의 일치**: a = ω_교사 − v·κ 를 나란해지는 순간을 기준으로 4 m 앞부터 거꾸로 적분했을 때 243/268 = 91 % 가 일치한다.
  - 중앙 113/123 = 92 %(v08r3 47/50, r3 66/73), 옆 130/145 = 90 % 이다.
  - 불일치는 대부분 r3 의 여러 번 출렁이는 접근이다.
  - 적분을 창 시작부터 하면 53–68 % 로 떨어진다. 한 번의 회피는 적분하면 0 에 가깝고 꺾기 시작 거리가 들쭉날쭉하기 때문이다.
- **꺾기 시작** 거리는 중앙값 3.7 m(사분위 1.9–4.8 m)이다(`traces.png` 위 그림). 그래서 '결정 전 상태'는 장애물 6 · 8 m 앞에서 쟀다.
- 괄호 안은 정확(Clopper–Pearson) 95 % CI, p 는 50 % 대비 정확 이항검정이다.

## 5. 재현성 — 같은 장면에서 Nav2 가 같은 쪽을 고르나

| 비교 | 중앙 | 옆 |
|---|---|---|
| 같은 배치 · 방향 · 장애물을 두 번 녹화 (r3 11.05 vs v08r3 11.11) | **33/44 = 75 % [60–87]** | 44/48 = 92 % [80–98] |
| → 기하로 맞힐 수 있는 상한 q (q² + (1−q)² = 재현율) | **≈ 85 % [72–93]** | ≈ 96 % |
| 같은 배치 cw · ccw 가 물리적으로 같은 쪽 (r3 / v08r3) | 17/31 · 9/15 (≈ 57 %) | 34/37 · 16/17 |

- 중앙에서 쪽이 갈린 11 건 중 8 건은, 6 m 앞에서 로봇이 장애물의 같은 쪽에 있었는데도 다른 쪽으로 지나갔다.
- 두 녹화는 씬판(v0.4b/v0.8) · 위치추정(AMCL/gt) · 교사 잡음이 다르다. 모두 카메라로는 거의 안 보이는 차이라서, 이 상한이 바로 '영상으로 정할 수 있는 만큼'의 추정이다.

## 결론

- **중앙 장애물의 쪽은 대체로 무작위에 가깝다** — 기하로는 약한 쏠림(≈ 2/3)만 있다.
  - 오프셋 부호와 위치를 써도 held-out 64–74 % 다.
  - 같은 장면을 반복 녹화해도 75 % 만 같다.
  - '더 세밀한 영상 단서 · 더 많은 데이터'로 올릴 수 있는 폭은 ≈ 85 % 까지다.
- 회귀가 배울 조건부 평균 크기는 (2p − 1) × 회피 폭이다. p = 0.68–0.74 이면 0.36–0.48, 상한 0.85 에서도 0.70 이다.
  - 그러므로 완벽한 영상 모델도 중앙 장애물에서는 약하고 늦게 꺾는다. (가) 는 데이터 한계로 성립한다(11.11 README 의 중앙 부호 일치 52–55 %, 크기 비 0.16–0.23 과 맞는 방향).
  - (나) 되먹임이 함께 있는지는 이 분석으로 가를 수 없다(E1 직전 명령 0 평가는 그대로 필요).
- **쪽이 정해지는 오프셋**:
  - 0.30–0.40 m 에서 90 % [76–97](서쪽 사선 빼면 93 %), 0.40 m 이상에서 100/103(서쪽 사선 빼면 77/77)이다.
  - 0.15–0.30 m 는 데이터가 없어 0.2 m 로 충분한지는 모른다.
  - **재녹화 권장**: 중앙 장애물을 기준선에서 **0.4 m 이상**(최소 0.3 m) 한쪽으로 비켜 둔다.
  - 서쪽 사선 · 모서리 근처는 피하거나, '같은 쪽' 규칙이 지켜졌는지 이 스크립트로 확인한다.
  - 기존 중앙 장애물 조우(121 건)는 학습에서 빼거나 가중치를 낮추는 것도 후보다.

## 3절 가르는 시험과의 관계

- 이 분석은 (나) 되먹임을 가르지 못한다 — E5 를 직전 명령 0 으로 평가하는 시험은 그대로 필요하다.
- 다만 판정 기준(E5_zero 중앙 부호 일치 ≥ 70 % → (나))은 교사 데이터 자체의 기하 규칙 적중률(68–74 %)과 거의 같다. 영상만으로 방향을 완벽히 정하는 모델도 중앙 장애물에서 70 % 근처가 한계일 수 있어, 60–70 % 가 나오면 '애매'가 아니라 데이터 상한에 붙은 것일 수 있다. 결과를 읽을 때 이 표의 같은 조우(중앙 · 회피 중)에서 교사 기하 규칙 적중률과 나란히 볼 것.
