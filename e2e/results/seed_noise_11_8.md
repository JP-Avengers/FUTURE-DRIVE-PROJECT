# 11.8 시드 차(규칙 3 기준선) — v0.1 vs seed1, 그리고 aw30 · p3 · v0.2 의 차이가 그보다 큰가

- **무엇**: v0.1(xm_v1 · 명령 가중 10 · 10 에폭 · 실효 배치 8 · seed 미지정)과 같은 설정에 `--seed 1` 만 더한 seed1(`xm_ft_v0.1_seed1/`, 레포 `7effa01`, Kaggle 커널 `fd-xm-finetune-aw30` 재사용)을 **같은 v1.0 test(4,753프레임 = 자동 교사 시계 5바퀴 4,068 + Nav2 슬라럼 시계 685)** 로 평가해 "같은 설정 두 run 의 차" = **바닥(noise floor)** 을 쟀다. aw30 · p3 · v0.2 는 모두 'v0.1 + 한 가지' 라, 각각의 v0.1 과의 차를 이 바닥으로 나눠 본다(PLAN 규칙 3).
- 모델(평가 run_meta 의 sha12): ZS `339c68f9e027` · v0.1 `d86970ce1faf`(best 에폭 8) · seed1 `78b34c3d7644`(에폭 9) · aw30 `4fdf249cda0a`(에폭 8, 명령 가중 30) · p3 `25b8ab2106af`(에폭 9, 경로 정답 ×1/3 = `xm_v1_0_p3`) · v0.2 `0fec1d572199`(에폭 9, xm_v1_2 = v1.1 + train Nav2 ×3 — v1.0 test 평가는 `reeval_v1.1_11_7/` 판 2). v0.2 만 학습 데이터 · val 이 다르다(v1.1).
- **판정 약속(이 문서)**: 바닥 = |seed1 − v0.1|. |x − v0.1| < 2 × 바닥 → **구분 불가**, ≥ 2 × 바닥 → 방향대로 **좋음 · 나쁨**. '2×' 는 규칙 3("시드 2개 차이보다 작은 개선은 같다")을 조금 보수적으로 쓴 것 — 두 run 차의 두 배까지 우연으로 본다 — 이고 통계 검정이 아니다. **시드 쌍이 하나뿐이라 바닥 자체가 불확실하다**: 우연히 작게 나온 바닥(자동 교사 2 s p95 0.0003 m · v MAE 0.0003 m/s · 부호 일치 0)은 배수가 커도 믿지 말고, 우연히 크게 나온 바닥(장애물 3 m 안 기울기 0.093)은 아무것도 못 가른다. 자동 교사는 5바퀴라 바퀴별 표(아래)로 바닥의 흔들림을 같이 본다.
