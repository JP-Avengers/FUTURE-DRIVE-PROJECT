# 11.11 장애물 회피 다시 보기 — 교사 입력 평가는 '복사'와 구별이 안 됨 → 11.10 판정 (나) 보류

## 한 줄

11.10 의 "(나) 직전 명령 되먹임, 다봉 평균 아님" 근거(교사 입력이면 중앙 장애물도 0.83–0.85 만큼 피함)는 **직전 교사 명령을 그대로 복사하는 것만으로 0.99–1.04 가 나와** 아무것도 가르지 못한다. 기본 평가의 중앙 장애물 부호 일치 54–55 % 는 동전 던지기 수준 — (가) 다봉 평균(영상으로 방향을 못 정함)도 살아 있다. 둘을 가르는 시험은 아래 '다음'.

## 근거 (v1.4 val · test, `obstacle_diag` 프레임별 + 직전 프레임 교사 a 를 그대로 쓰는 '복사' 기준)

같은 지표(회피 중 · 연속 프레임만, 부호 일치 · 크기 비 = Σ 예측 a · sign(교사 a) / Σ |교사 a|):

|---|---|---|---|---|---|
| test 중앙 (128) | 98 % · 0.99 | 97 % · 0.86 | 55 % · 0.17 | 52 % · 0.16 | 45 % · 0.09 |
| test 옆 (129) | 98 % · 1.03 | 94 % · 0.91 | 53 % · 0.33 | 55 % · 0.40 | 43 % · 0.04 |

- 교사 a 는 5 Hz 에서 프레임 사이 상관 0.95–0.97. 교사 입력 aw30 은 교사 a(t) 와도 a(t−1) 과도 0.95–0.98 상관 → 둘이 구별이 안 됨.
- 교사 a 가 크게 바뀌는 프레임(|Δ| 상위 20 %, 복사로는 못 맞히는 곳)에서 교사 입력 aw30 은 변화의 0.32–0.47 만 따라감 → 대부분 복사.
- 그림 `avoid_vs_dist.png`(거리별 평균, 에피소드 3–6개라 들쭉날쭉): 교사 입력 곡선은 교사와 거의 겹치고, 기본 평가는 일부 구간만 맞는 쪽.

## 뜻
